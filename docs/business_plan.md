# 事業計画書
個人事業主：黒猫フルスタック
使命：AIによる業務再設計

## 1. 事業概要
黒猫フルスタックは、AI導入を目的とせず、AIが主役になれる業務構造そのものを再設計する支援を行う個人事業です。
多くの企業では、判断基準が整理されないままAIを導入し、結果として業務の混乱・属人化・責任不明確化を招いています。
黒猫フルスタックは、AI導入の前段階である**「業務の判断構造の整理」**を最重要とし、人とAIの役割境界を設計することで、最小の導入で最大の事業効果を生むことを使命とします。

## 2. 使命・基本原則
### 使命（Mission）
AIによる業務再設計

### 基本原則（黒猫フルスタックの流儀）
- 判断が整理されていない業務にAIは入れない
- AIは万能化しない。主役にできる領域だけを任せる
- 人が担う判断と責任を、業務として明示する
- 業務が変わらないAI導入は支援しない
- PoCを目的とした支援は行わない

## 3. 提供価値（Value Proposition）
### 黒猫フルスタックが提供する価値
- 社員による判断のばらつきを構造として可視化
- AIに任せられる判断と、人に残す例外の明確化
- 判断責任を含めた業務プロセス再設計
- 実装ありきではない、経営判断に使える診断成果

### 提供しない価値（明確な非対象）
- AIツール・ベンダーの紹介
- 仕様書通りの開発受託
- 運用保守前提の業務
- 暗黙知のAI化
- 判断責任を曖昧にした自動化

## 4. 対象顧客
### 主対象
- BtoC／BtoBを問わず、製品・サービスに関する問い合わせ業務を持つ企業
- AI導入を検討しているが、業務整理が追いついていない企業
- 経営として業務ルール・判断基準に関与する意思がある企業

### 非対象（原則支援しない）
- 医療・薬品関連
- 投資アドバイス関連
- 脱法行為・ハック目的
- 業務を変えずにAIだけを入れたい企業

## 5. サービス内容
### ① 無料：業務構造チェック（30分）
- 目的：選別のみ
- 判断ばらつきの有無確認
- データ・責任者の有無確認
- 有料診断に進む可否判断
※ 提案・改善案提示は行わない

### ② 有料：業務構造診断（本体サービス）
- 期間：2〜3週間
- 価格：30万〜50万円（税別）
- 内容
    - 問い合わせデータ確認
    - 定型／例外／判断ポイントの分解
    - AI適用可否判断
    - 人とAIの役割境界設計
- 成果物
    - 業務構造サマリー（5〜10枚）
    - AI適用判断メモ（経営向け1枚）

### ③ 設計・実装支援（任意・別契約）
- 診断後、必要な場合のみ実施
- 内製前提、短期・限定的関与
- 運用保守は行わない

## 6. 競争優位性
### 差別化ポイント
- AI導入を急がせない立場
- 技術ではなく判断構造が主戦場
- 「断る」ことを前提とした設計
- 実装しなくても価値が残る成果物

### 代替困難性
- 業務×IT×AI×組織を横断した経験
- 保険業界での長期実務・再建案件経験
- 現場・経営双方との合意形成能力

## 7. 営業・集客戦略
### 基本方針
- 広告は行わない
- 思想によるフィルタリングを最優先

### 主な導線
- Webサイト（使命・原則を明示）
- 解説記事（「AI導入を急がせない理由」等）
- 紹介・再相談（半年〜1年後）

## 8. 収益モデル
### 想定単価
- 業務構造診断：30〜50万円／件
- 実装支援：案件ごとに個別見積

### 年間モデル（例）
- 診断：月2件 × 12ヶ月 = 24件
- 平均単価40万円 → 約960万円
- 実装支援：選択的に追加
※ 件数より「消耗しない継続」を重視

## 9. リスクと対策
| リスク | 対策 |
| :--- | :--- |
| 案件数が少ない | 高単価・紹介前提 |
| 技術進化 | 特定技術に依存しない |
| 属人化 | 診断プロセス・原則の明文化 |
| 断るストレス | チェックシートによる客観判断 |

## 10. 中長期ビジョン（2026〜）
- 業務構造診断のフレームワーク化
- 再現可能な判断設計モデルの確立
- 小規模だが高信頼な専門ブランドの確立
- 「AI導入を断る専門家」としてのポジション確立

## 11. 最終宣言
黒猫フルスタックは、AI導入を急がせる存在ではない。
判断が整理された業務だけに、AIを主役として迎え入れるための設計者である。
